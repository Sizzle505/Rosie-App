# Rosie App

A standalone Rosie-themed experience.

## Current feature

**Madame Rosie** - a Zoltar/Magic-8-Ball-inspired fortune teller that uses a fixed library of 30 canine responses. No active model or backend is required for the initial version.

### Included
- React + Vite
- Mobile-first fortune teller interface
- 30 prewritten responses split across positive, uncertain, and negative categories
- Secure random selection
- Suppression of recent answers during a session
- Loading screen and fortune-reveal animation
- Local saved-fortune storage
- Shell for future Cards, Gallery, and Rosie sections

## Development

```bash
npm install
npm run dev
```
