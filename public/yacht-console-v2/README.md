# Yacht Dash console artwork

Generated for the Captain page using the built-in image generator, then integrated as WebP assets.

- `treat-turbo.webp`: transparent 2172 × 724 button face. The application overlays the live TREAT TURBO label and charge percentage on the right side.
- `nautical-lacquer.webp`: 1254 × 1254 ocean lacquer material used across the Yacht console and its individual instrument/control panels.

The original illustrations are preserved; neither replaces gameplay scenery or characters.

## Treat Turbo prompt

Use case: stylized-concept. Asset type: production mobile game UI button artwork for Captain Rosie's Yacht Dash, an ornate Japanese nautical fantasy arcade. Create a single very wide horizontal rounded rectangular button, front-on orthographic view, about 3:1 width to height, isolated on a truly transparent background. Substantial richly sculpted polished gold and brass rim, dark ocean teal/navy vitreous enamel interior, beautiful restrained Japanese curling wave relief, small warm amber highlights. At the LEFT QUARTER only, a charming raised golden dog-bone treat with a pearl white center, nestled into a miniature bronze ship propeller and curling turquoise wake, communicating a treat-powered nautical turbo. Remaining RIGHT TWO THIRDS a calm continuous deep teal enamel surface for live HTML lettering to be placed later, subtle engraved waves and very fine gold details rather than empty flat color. Lavish premium illustrated 3D game art, crisp highlights, finely hand painted dimensional material, matches ornate gold-framed sailing game controls, no cartoon flat vector. Entire outer edge visible with minimal transparent margin. NO WORDS, NO LETTERS, NO TYPOGRAPHY, NO WATERMARK, no character faces, no space or drill imagery.

## Nautical material prompt

Use case: stylized-concept. Asset type: actual surface texture for a luxury Japanese nautical mobile game control console, not a picture of a console. Create a square full-bleed richly detailed dark ocean navy / deep teal lacquer texture with continuous elegant Japanese seigaiha wave arcs, embossed flowing ocean current filigree and finely etched antique brass/gold contour lines. Tiny subtle mother-of-pearl inlay accents suggesting sea foam, richly lustrous but predominantly DARK and understated enough behind pale gold live UI numbers. Consistent material detail and visual density throughout including the center; no empty center void, no central medallion or object, no frame, no text, no controls, no buttons, no scenery horizon, no characters. Uniform top-down orthographic material surface. Beautiful tactile hand-painted 3D fantasy nautical enamel and brass, gently varied highlights across the entire texture. Gold engraving is thin and restrained, never a loud bright grid. Suitable to cover every panel of Captain Rosie's ornate Japanese sailing adventure UI.
