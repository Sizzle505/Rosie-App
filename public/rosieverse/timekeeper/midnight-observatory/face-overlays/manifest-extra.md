# Timekeepers - Five Additional Inner Dial Overlays
These five transparent face overlays are derived from the artwork generated for the Rosie Timekeepers revamp. They are interchangeable decorative *face layers*, not clock bezels.
Each is normalized to 448 × 448 WebP, has a transparent center for analog hands and digital readouts, and uses the same dial fit as the existing overlays.

| File | Selection |
|---|---|
| sunburst.webp | Sunburst |
| deco.webp | Art Deco |
| moonlight.webp | Moonlight |
| pearl-baroque.webp | Pearl |
| emerald-filigree.webp | Emerald |

Original 512 × 512 source-processed masters and source manifest are archived in Dropbox under Rosie-App-Transfer/Timekeepers Asset Pack - Midnight Observatory/Timekeepers Five Face Overlays 20261015.zip.

All Timekeepers modes use the existing independent bezel and one common centered dial coordinate system.
