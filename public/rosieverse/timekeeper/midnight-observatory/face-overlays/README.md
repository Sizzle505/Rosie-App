# Timekeepers interchangeable clock overlays

The four clock-face sources were transferred through Dropbox to:
`/Rosie-App-Transfer/Timekeepers Asset Pack - Midnight Observatory/`

| Style | Source | Optimized application asset |
|---|---|---|
| Roman | Timekeeper Overlay Roman 20261014.png | roman.webp |
| Batons | Timekeeper Overlay Batons 20261014.png | batons.webp |
| Chronograph | Timekeeper Overlay Chronograph 20261014.png | chronograph.webp |
| Celestial | Timekeeper Overlay Celestial 20261014.png | celestial.webp |

All four optimized overlays are 640 × 640, RGBA WebP, with transparent centers. The current Timekeepers clock continues to use its own separate shell and bezel. CSS aligns the overlay to the center of the face in a shared 69%-diameter window. The dial can be switched independently between sapphire, emerald, garnet, and obsidian enamel backgrounds using the small star control on the blue instrument cabinet. Both choices persist locally.

The newly generated alternative full-body Rosie images were deliberately **not** integrated: their black backgrounds and paw/lever registration do not meet animation-sprite requirements. The existing aligned Rosie atlas remains intact.
