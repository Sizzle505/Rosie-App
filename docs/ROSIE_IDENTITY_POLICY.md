# RosieVerse - Rosie Identity Policy

**Applies to:** Every depiction of Rosie in Rosie App / RosieVerse: UI artwork, illustrations, cards, icons, animations, prompts, marketing renders, and acceptance checks.

## Canonical photographic reference

The user's actual Rosie photographs have been preserved privately in ChatGPT Library:

`/RosieVerse/Canonical-Identity/`

- `rosie-real-front-tuxedo.jpeg` - primary frontal identity photograph.
- `rosie-real-three-quarter-race.jpeg` - secondary three-quarter identity photograph.
- `rosie-reference-contact-sheet.png` - side-by-side visual aid derived from those originals.
- `ROSIE_IDENTITY_RULE.md` - complete reference and image-generation policy.
- `RosieVerse_Identity_Reference_Pack_20261010.zip` - portable master handoff, including style examples, an image manifest, and original source photographs.

The repo is **public**, so the personal photographs are intentionally stored in the private ChatGPT Library, not committed here. The Library files must be explicitly retrieved for photo-guided generation. The same reference pack can be attached to any new session when private Library retrieval is unavailable.

## Non-negotiable likeness workflow

1. Locate **both actual photographs** and visually inspect them before creating or editing Rosie artwork. Reference the exact files used, not just this policy.
2. Use those photos as the **identity source of truth**. Preserve Rosie's actual head and muzzle geometry, upright ears, dark almond-shaped eyes, black nose, precise tan eyebrows/cheeks/legs, creamy muzzle and chest, black coat, and compact body proportions.
3. Do not substitute generic black-and-tan Shiba breed appearance. In particular, avoid a rounded plush teddy-bear head, exaggerated grin, constant tongue-out expression, or facial markings invented to suit the art.
4. Existing AI-generated Rosie cards and app illustrations are **style/layout/iconography references only**, not reliable identity references. No generated image replaces the photographic anchors.
5. Verify the new output visually against the real photos. If the outcome looks like a similar dog rather than Rosie, reject and redo it.
6. If photo assets cannot be retrieved or cannot be passed to the image-generation workflow, **do not generate or claim identity accuracy**. Ask for reattachment or provide an explicit handoff. Never claim the reference was used based on memory, filenames or descriptive prose alone.

## UI icon guidance

For RosieVerse landing pages, the destinations are **Fortune Teller**, **Cheese Board Exam**, **Captain Rosie**, **Card Vault**, and **Randomizers**. Buttons should be coherent in scale and typography. Use restrained, legible iconography (crystal ball, cheese and diploma, ship/wheel, card vault, dice), and **do not put Rosie headshots in every tile**.

## Limits

This GitHub policy is readable to future repository agents. It is not itself an image attachment. ChatGPT Memory and text-only project rules can communicate the workflow, but cannot guarantee that an image model has received the photographic pixels. Every session must verify that separately.
